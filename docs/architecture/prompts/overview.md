# 完整模型结构图提示词

整段复制下面三个部分。只有“画面内容”指定的对象进入图内；其余文字用于约束绘图或作为图外图注。本页不要求生成 drawio 文件。

## 画面内容（需要画进图里）

绘制一张横向16:9的论文模型结构图，使用可由 drawio 基本形状搭建的风格。参考 Xiaomi-Lens-0 第5页 Figure 2 的语言模型长条、输入输出小方块和右侧解码器放大框，结合 SOVS-Net 第4页 Figures 1–2 的特征网格与叠层矩阵。无需原论文也可按以下布局绘制；不要照搬它们的算法。

白底，无渐变、阴影、品牌标志或装饰。线宽约1–1.5 pt，连接线水平/垂直折转，箭头端点贴合模块。英文标签使用 Arial，普通标签最多两行、原则上不超过5个词。模块名称用细边框内的短标题，不加画布大标题。图像信息蓝色 #4477AA，文字橙色 #EE9944，输出绿色 #228833，训练约束紫色 #AA3377，标签资料灰色 #777777；填充使用相应颜色的浅色版本。

### 主体布局：上方75%

上方左侧约70%宽为主模型，右侧约30%宽为区域输出放大框；从左侧输入组织到中央长条，再到右侧输出。图中主要对象是图像、网格、向量小方块和模型层，不是步骤卡片。

左下放灰度SAR示意图，标 `SAR Image`，输入边旁小字 `SAR Input Adapter`，接蓝色矩形 `Qwen Native Vision Encoder`。其输出画有网格的薄层块，标 `F`。F必须有两个明确出口：一个经 `Native Visual Merger` 转为蓝色小方块序列，进入中央语言模型；另一个沿主干外侧直接进入右侧区域输出放大框。

左侧另放两行短文字输入，分别标 `Target Text` 和 `Question`。用橙色小方块表示文字输入，连中央横向长条 `Qwen Language Model`，长条旁小字 `Qwen3.5-0.8B`。用清晰分隔的调用端口表达三种用途：`Grounding`、`Target-only`、`Answer`，不要在长条内部堆叠三张说明卡片。

`Grounding` 端口接图像表示与由目标文字构成的圈选指令，其输出为橙色单向量 `h_q`；`Target-only` 端口只接目标文字，其输出为 `h_t`；`Answer` 端口接图像与问题，输出橙色回答小方块序列，经 `LM Head` 到绿色小框 `Language Answer`。这些是同一模型的不同调用，端口间不画串行箭头。

在主干上方靠右画 `Shared Text Projection`，接 `h_t`，输出小向量 `u_t`，送右侧放大框。投影旁标共用标识 `P_t`，不要为描述另设一套独立投影。

右侧放大框标题 `Lightweight Mask Decoder`。F进入 `Shared Visual Projection`，旁标 `P_v`，输出叠层网格 `X`；`h_q` 经 `Query Projection` 与输入 `u_t` 在圆形加号节点相加。X与合并向量进入圆形相似度节点，旁标 `Cosine`，输出二维得分网格，经 `Upsample` 得绿色轮廓与黑白掩码 `Predicted Region`。P_v包含打分前的视觉处理，不能再另画一个完整解码器。

### 训练附图：下方25%

用一条薄虚线分隔下方，左上标 `Training only`，不铺巨大灰色面板。左端小幅标签区域与文字条标 `Verified Region Facts`，旁标 `Support`；连接紧凑的 `Confusion-Aware Pair Construction` 区域，内部直接画区域小图、文字条及带 `+ / − / ?` 的对应矩阵 `C`，不用步骤列表。

右侧相邻区域标题 `Bidirectional Region-Text Alignment`，内画区域向量 `r`、描述向量 `d`、相似度矩阵 `S`，从矩阵的行、列各引出一条短箭头至 `L_R→T`、`L_T→R`，合为 `L_align`。C通过短虚线进入对应选择。

右侧上方的X向下分支到小型 `Masked Pool`，训练掩码只通过监督虚线进入此处，池化后得到r。训练描述经下方单独的小框 `Qwen Language Model` 和 `Shared Text Projection` 得到d；分别使用 `θ_L`、`P_t` 与主图同名部分对应，避免用横跨画布的共用连线。上下调用只共用参数，描述状态不得沿实线回流上方。

在主图原生视觉模型及P_v旁放小紫色 `Δθ_v`，语言模型及P_t旁放 `Δθ_L`，附图L_align旁重复这两个标识；角落一行小字 `Δθ: alignment updates`，表达新增约束作用到两侧，不画跨图反向长箭头。主体语言模型也标 `θ_L`。

训练附图边缘只放 `L_seg`、`L_lang` 和 `L = L_seg + L_lang + λL_align`。区域预测接L_seg，回答预测接L_lang；标签和标准答案用紧邻损失的小灰符号及监督虚线表示，不绕行整张图。无目标画一个小空掩码 `Absent target`，只连分割和语言监督，不连匹配向量。

图例只占一行：`Solid: features; dashed: supervision`。相同参数符号表示共用，不把这种关系画成输入传递。分区标题可保留全名，其余文字保持短小。

## 绘图约束（不要画成说明框）

保持当前目标设计的连接：X来自圈选的视觉路径，P_t同时用于目标文字和训练描述。固定网格坐标可用；标签计算的面积、中心和长宽比不能直接拼入表示。原生视觉经合并进入语言模型之前，必须另有F到区域输出的直接连接。

不得照搬 Xiaomi 的特殊 `<|mask|>` 标记、由生成回答触发圈选的顺序或转置卷积层数；不得加入 SOVS 的多阶段解码器、最优传输、冻结标志或特征金字塔。也不加独立大型分割模型、旧版两项增强模块或多轮区域修正。

真实标签、描述标准答案、困难类别表不是自主预测输入。纯目标编码与图像问答共用模型，不代表混合输入或一次计算完成。禁止人物、齿轮、聊天气泡、文档图标、流程编号、大图例、解释段落、A/B横幅以及交叉缠绕的箭头。
