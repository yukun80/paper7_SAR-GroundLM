# 共享区域—语义双向匹配结构图提示词

整段复制下面三个部分。用共享表示与矩阵运算展示模块结构；不要把学习过程画成循环预测，也不要把图外规则排进画面。

## 画面内容（需要画进图里）

绘制横向16:9论文模块图，使用 drawio 可搭建的基本形状；白底、细线、低饱和浅色填充，无阴影或渐变。

图像蓝色 #4477AA、文字橙色 #EE9944、输出绿色 #228833、训练约束紫色 #AA3377、标签灰色 #777777。英文Arial字体，普通标签最多两行、原则上不超过5词；线宽约1–1.5 pt，正交连接线。顶端短分区标题 `Bidirectional Region-Text Alignment`，旁注 `Core Component 2`，匹配计算区以薄虚线边界标 `Training only`，不铺大灰底。

### 左侧30%：与圈选共用的视觉表示

蓝色矩形 `Qwen Native Vision Encoder` 输出薄层网格 `F`，经 `Shared Visual Projection` 得到更细的叠层网格 `X`。投影旁标 `P_v`。X向上用一条短线连至绿色小标签 `Mask Decoder`，表示主任务实际也使用此表示，不再画第二套主模型。

X向内分支到训练区的 `Masked Pool`。训练掩码画成贴近X的小型黑白网格，以监督虚线进入池化权重端，标 `Region Mask`；忽略位置用灰斜线及短标签 `Ignore 255` 表示。掩码覆盖示意只能放在池化分支，不能画在生成X的输入上。

池化后画多条蓝色小向量 `r_1 … r_n`，纵向排布并接中央矩阵的行。保留归一化的小算子 `Normalize`，不要增加独立区域投影。区域掩码只决定汇聚权重，不提供中心、面积或长宽比数值。

### 右侧30%：与目标文字共用的文字表示

几条橙色短描述 `Region Descriptions` 经小方块序列进入 `Qwen Language Model`，旁标 `θ_L`，再经 `Shared Text Projection`，旁标 `P_t`，经 `Normalize` 得向量 `d_1 … d_m`，对齐中央矩阵的列。

投影外侧放短支路：`Target Text` → 参数θ_L的 `Target-only` 调用端口 → `h_t` → 同名投影的轮廓副本 `P_t` → `u_t` → 绿色 `Mask Decoder` 标签。两份投影用无箭头短细线标 `Shared weights`。纯文字调用端口与描述端口分开，不把训练描述当作目标输入，也不把原始文字直接送进投影。

θ_L也用于主任务问答；在语言模型旁用短标 `Shared with answering` 说明，不重画一条完整回答流程。目标调用和描述调用分别画端口，状态不相互流入；重复轮廓只是同参数的另一次调用，不是新增网络。

### 中央40%：相似度矩阵与两个方向

中央大矩阵标 `S`，左边对齐蓝色区域向量，上边对齐橙色描述向量；矩阵上方仅写 `S = R Dᵀ / τ`，不填任何虚构实测分数。用浅深单元格示意相似度，但不能将底色当作正负真值。

矩阵旁的小对应表标 `C`，入口短标签 `Pair Construction`，通过监督虚线进入有效对应选择。C的正负用 `+ / − / ?` 表示，允许多正确对应，不确定格用斜线遮罩；不要根据S的高低改写C。

从S的右侧引出一条横向短箭头，标 `Region-to-Text`，连 `L_R→T`；从S的下侧引出一条纵向短箭头，标 `Text-to-Region`，连 `L_T→R`。二者在下方汇入小节点 `L_align`。这两条箭头是在同一矩阵上按行和按列计算，不是区域与文字来回生成。

在C中至少示意一行两个正号和一个问号；旁边小图例 `+ Match   − Mismatch   ? Ignore`。图内不展示完整对数损失推导、锚点筛选列表或数值设置。

### 学习影响与连接标记

在视觉模型及P_v旁各放小紫色 `Δθ_v`，语言模型及P_t旁各放小紫色 `Δθ_L`，L_align旁重复两种标识。底边一行小字 `Δθ: alignment updates`，表示该约束影响共用投影及两侧上游模型的可训练部分；不画穿越整个图的反向回线。

保留一行简短线型说明 `Solid: features; dashed: supervision`。共用参数只用同名符号及局部无箭头线，不让参数关系看起来像预测输入；也不使用冻结雪花、火焰或品牌图标。

## 绘图约束（不要画成说明框）

X为轻量圈选解码器打分前的视觉网格，固定网格坐标可保留；r与d均为128维。掩码与有效范围相交后以面积平均生成池化权重，保留小区域分数权重，分母为0时跳过。禁止标签几何统计直接拼入向量，禁止新增独立区域/描述匹配投影。

每个方向的锚点至少有一个正确和一个明确错误对应；损失为负对数“正确对应指数分数之和/全部可信对应指数分数之和”。问号从分子分母同时排除，方向内对有效锚点平均，再对有效方向平均；两个方向均无有效项则附加损失为0。完整公式留在设计说明，不画成图内段落。

无目标不生成空区域正匹配，仍参与分割与存在性语言监督。A、B相同架构和正确语言内容，仅B启用附加约束；初始λ=0.1、τ=0.07是待验证设置，不画成已证明最优的参数。

禁止步骤清单、决策菱形、齿轮、人物、聊天气泡、大图例、交叉长箭头；禁止真实标签进入自主预测、标准答案回送圈选、特殊掩码标记、多轮预测修正、SOVS最优传输或独立大型分割模型。

## 图外图注与核对（不塞入结构图）

英文图注保留 `Proposed architecture; effectiveness unverified.` 与 `Schematic example`。说明共用投影、去掉几何统计直接输入及多正确对应属于待实施完善；模型有效性尚未验证。正文解释A/B公平条件、无目标比例和计算边界。

核对X确实连圈选与池化，P_t确实连目标与描述，训练掩码仅控制池化，两个匹配方向读取同一矩阵，两侧上游模型均有新增约束作用标记。共用参数不等于不同调用混合输入。
