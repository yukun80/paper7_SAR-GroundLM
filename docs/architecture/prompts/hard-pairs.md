# 易混淆区域—描述组合图提示词

整段复制下面三个部分。此图用区域阵列与对应矩阵表现组合关系，不用样本筛选的步骤流程；只将“画面内容”列出的内容画入图内。

## 画面内容（需要画进图里）

绘制横向4:3论文模块图，白底、细边框、浅色填充、无阴影与渐变，采用 drawio 可搭建的网格、图像小块和文字条。英文Arial字体，普通标签最多两行、原则上不超过5词。

图像蓝色 #4477AA，文字橙色 #EE9944，输出绿色 #228833，约束紫色 #AA3377，标签灰色 #777777；使用低饱和浅色填充。线宽约1–1.5 pt，连接用水平/垂直短线，不画横跨样例的交叉关系网。顶端短标题 `Confusion-Aware Pair Construction`，旁注 `Core Component 1`、`Training only`。

### 中央主体：由区域和文字围成的4×4矩阵

中央偏右放矩阵 `C`，约占画面宽度45%；四行旁直接对齐四张训练区域小图 `R1` 至 `R4`，四列上方对齐四条描述 `D1` 至 `D4`。描述可分两行，不能让标签遮住矩阵。

四张图都是示意训练图片，蓝色轮廓表示被查询区域，其他类别用灰线/纹理区分；不根据模型结果选图。R1：左上水域，道路在其右侧且有明确标注。R2：另一张图的左上水域，道路参照无法从标注确认。R3：右下建筑区域。R4：右上水域，道路仍明确位于该水域右侧。每个目标均使用本图内该类全部有效像素，范围一致。

四条描述固定为 D1 `Water in upper-left`，D2 `Upper-left water region`，D3 `Built-up in lower-right`，D4 `Water left of road`。D1与D2有意表达同一事实，D4有意省略绝对位置；不能额外添加面积、材质或用途限定。

矩阵按行准确填为：R1 `+ + − +`；R2 `+ + − ?`；R3 `− − + −`；R4 `− − − +`。正号用浅绿底，负号用浅紫底，不确定格用灰斜线。矩阵边一行小图例 `+ Match   − Mismatch   ? Ignore`。颜色只辅助符号，不制造只能靠颜色阅读的图。

用小括号标出R1/R2与D1/D2形成的四个正确格，标签 `Multiple positives`；R2–D4的问号旁标 `Unknown reference`。不要强迫只有对角线为正，也不要把相同文字或跨图对应自动判错。

### 周边小标记：困难来源与错误类型

左上只放一个小型类别清单条 `Frozen dev groups`，用一条短虚线指向区域阵列，线上短标 `Class selection`；阵列标题 `Training regions`。清单不写猜测的困难类别名，不放开发图片或开发分数，不展开混淆统计流程。

在矩阵外侧以短引线点到三处示例：R3–D1标 `Class mismatch`；R4–D1标 `Location mismatch`；R1–D3标 `Region mismatch`。这些是错误类型说明，允许同一对应涉及多种事实矛盾，不画三个串联网络。

矩阵右下仅有一个出口 `C`，连到小标签 `Bidirectional Region-Text Alignment`，表示下游使用这张对应表。矩阵本身和事实判定不是可训练分类器，不加梯度或参数共享图例。

## 绘图约束（不要画成说明框）

所有区域与实际组合只来自训练图片；开发结果只固定类别清单，最多三组且每类至少三张正例图、256个有效目标像素，不足两组停止困难比较。门槛和停止规则留在图外，不能变成矩阵旁的步骤卡片。

候选优先困难类别、同类不同位置和其他明确区域错配；当前目标设计每张图最多两个候选，每次更新两张训练图。示意阵列用于说明判定，可汇集不同更新的例子，不声称四图同时组成一次训练更新。示意类别不代表已选定困难类。

只根据描述明确表达的事实判定：全部支持为正，存在明确矛盾为负，无法核验为问号。同句描述在另一张图同样成立仍为正；数值取整不能制造假负例；关系参照不明则排除。问号既不进入正匹配也不进入负匹配。

错误描述只作匹配约束，不作为正确语言答案。无目标仍参与原分割和存在性语言监督，但不占矩阵行列；没有可信正负对应的锚点跳过附加项。以上规则不必另画一条旁路。

禁止筛选流水线、决策菱形、文档图标、三套独立创新网络、仅对角线正确、用测试集选类别或未知对当负例。不得画任何真实标签流向自主预测的连接。

## 图外图注与核对（不塞入矩阵画面）

英文图注保留 `Proposed architecture; effectiveness unverified.` 与 `Schematic example`。说明A、B获得相同正确文字和基础结构，仅B增加匹配约束；矩阵示例不是实际混淆统计，也不是准确率热图。

逐格核对示意区域与四条描述：R1/R2支持同一位置描述；R1/R4同时支持相对道路关系；R2的参照未知；R3类别明确不同。错误类型标记只解释示例，不改变三态判定。
