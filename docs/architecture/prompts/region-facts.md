# 可信区域事实图解提示词

整段复制下面三个部分。此图是区域与事实的对应图解，不是网络结构或步骤流程图；只将“画面内容”列出的对象画入图内。

## 画面内容（需要画进图里）

绘制横向4:3的论文区域图解，采用 drawio 基本形状、细边框与网格。白底、无渐变和阴影、Arial英文标签，普通标签最多两行、原则上不超过5词。

图像蓝色 #4477AA、文字橙色 #EE9944、输出绿色 #228833、监督紫色 #AA3377、标签灰色 #777777，填充使用浅色版本。细线约1–1.5 pt，只有明确输出关系使用箭头，其他注释用无箭头引线。顶端短分区标题 `Verified Region Facts`，旁注 `Supporting step` 与 `Training only`，不加大标题横幅。

### 左侧35%：同一图像的区域与有效范围

放一张SAR灰度示意底图与一张同尺寸标签覆盖图，二者上下对齐。覆盖图中左上画细长水域，右侧画道路参照区域；用蓝色边线突出水域，灰色细线标道路，短标签分别为 `Water`、`Road`。

标签覆盖图左下的一小块用灰色斜线表示 `Ignore 255`，不要涂成背景类别。外框标 `Labeled support`，水域标 `Class-union Region`。本例水域全部有效像素组成同一范围，后续各个放大图必须引用同一区域，不能悄悄换成其中一块。

### 中间40%：围绕区域的事实放大视图

中央画水域轮廓，周围排列四个小视图，用细引线指向同一轮廓，不用串行箭头，不画“提取—判断—生成”流程。

左上小视图 `Location`：九宫格中点出水域中心，短标签 `Upper-left`。右上小视图 `Area`：用目标有效像素和全部有效像素的两个小网格表示面积比例，斜线忽略区不计入分母；不写没有实际计算的百分数。

左下小视图 `Shape`：画水域细长轮廓及长短方向示意，标 `Elongated`，不画3D物体或材料纹理。右下小视图 `Relation`：同时画水域与道路的中心，水平位置清楚显示水域在道路左侧，标 `Left of road`。

类别用中央轮廓旁的短标签 `Class: water` 表示，不为每条事实增加独立处理模块。关系视图必须含道路参照；忽略区不可被当作参照类别。

### 右侧25%：对应描述与小型对照

放三条橙色文字条，分别写 `Water in upper-left`、`Elongated labeled region`、`Water left of road`。从相应视图用短引线对应文字；它们是同一区域的受支持事实，不是模型预测回答。

右下放小型无目标对照：同一标签示意图、查询短条 `Airport`、空白掩码 `Absent target`。空掩码旁只放短标记 `Segmentation + language`，不画区域向量或匹配网络，不把无目标例子扩成一条流程。

图中以轮廓、位置网格和有效像素说明事实来源，文字条总共不超过上述三条。没有参数共享、梯度、编码器或创新编号，因为本图不含可训练模块。

## 绘图约束（不要画成说明框）

事实仅由训练标签支持：类别、位置、有效面积比例、已标注几何和明确参照关系。位置采用九宫格中心；关系采用图像宽高5%的中心对齐容差；面积文字取整但核对保留精确值。这些计算规则留在图外，不能变成图中的规则清单。

水域、道路、位置和描述必须相互一致。不能凭标签推断用途、材质、散射原因或物体完整形状；未标注位置不计入正负学习或评分。无目标只表示有效标注范围内不存在该类；整张无有效标注不能画成已确认无目标。

若以后改用选定语义连通块，范围与文字必须同步标清，不能声称它是实例标注。本例默认类别全区域，不额外加入连通块分支。事实数值只作描述与对应核验，禁止画向自主预测或匹配表示的直接数值输入。

禁止步骤编号、决策菱形、数据库圆柱、人物、齿轮、文档图标、长句卡片、大图例、虚构性能或第三项创新。轮廓放大视图是几何示意，不是新的模型组件。

## 图外图注与核对（不塞入图解）

英文图注保留 `Proposed architecture; effectiveness unverified.` 与 `Schematic example`，并说明标签支持不等于独立专家审核。A、B使用相同正确描述；无目标约四分之一，参与分割与存在性语言监督，不生成空区域正匹配。

核对四个事实视图使用同一区域范围、面积分母排除255、关系有明确参照、无目标未进入非空匹配。图内只保留短标签和示例，计算公式与实验规则均放图外。
