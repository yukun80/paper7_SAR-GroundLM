# 目标架构与制图提示词

本目录面向论文完善 SAR-GroundLM 的目标设计，交付说明和提示词，不包含生成图片。图中文字用英文，说明用中文。**目标设计不等于当前程序，也不等于方法已经有效。** 当前基础学习仍未通过，实际状态只以[实验结果](../results.md)为准。

## 阅读与使用

先读[完整设计](design.md)，再整段复制对应提示词。每份分为“画面内容”“绘图约束”“图外图注与核对”：仅第一部分指定的对象进入图内，约束要遵守但不排版成说明框，图注单独使用。四份均可独立使用，无须附上其他文档。

| 图件 | 提示词 | 要讲清的内容 |
|---|---|---|
| 完整架构总图 | [overview.md](prompts/overview.md) | 语言模型主干、图像与文字表示、区域输出放大图及训练附图 |
| 支撑步骤图 | [region-facts.md](prompts/region-facts.md) | 同一区域的位置、面积、轮廓与参照关系图解 |
| 核心组成一 | [hard-pairs.md](prompts/hard-pairs.md) | 区域阵列、描述阵列及允许多个正确对应的矩阵 |

## 统一制图约定

- 以 [Xiaomi-Lens-0 第5页 Figure 2](../../doc/参考文献/P041_Xiaomi-Lens-0%20Technical%20Report__0ffa7116f2.pdf#page=5) 的模型主干与局部放大为主，结合 [SOVS-Net 第4页 Figures 1–2](../../doc/参考文献/SOVS-Net.pdf#page=4) 的网格、叠层表示和矩阵；只借鉴画法，不迁入其算法。
- 采用 drawio 基本形状可搭建的白底、细边框、正交连接和低饱和浅色填充；不生成 drawio 文件。图像蓝色 `#4477AA`、文字橙色 `#EE9944`、输出绿色 `#228833`、约束紫色 `#AA3377`、标签灰色 `#777777`。
- 特征网格、向量小方块、图像和矩阵是主体；不用人物、齿轮、聊天气泡、品牌标志、渐变或阴影。普通英文标签原则上不超过5词、最多两行，完整名称作分区标题；不加大标题横幅、说明段落或大图例。
- 实线箭头表示信息，虚线箭头表示监督；相同参数符号或无箭头局部细线表示共用。匹配学习对两侧的作用用局部 `Δθ` 标记表达，不画跨图反向长回线；事实图和组合图不伪造可训练参数。
- 用薄虚线边界或简短 `Training only` 标记区分训练内容；不再要求巨大灰色训练面板。不同调用只共用参数，训练描述不得沿实线进入自主预测。
- 图注统一保留 `Proposed architecture; effectiveness unverified.` 与 `Schematic example`；A/B规则、无目标比例、筛选门槛、跳过规则和完整公式放图外，不塞进模型画面。
- 一项核心方法包含两个核心组成部分，事实整理是支撑步骤；不为它虚构神经网络。总图展示连接，模块图展开结构，不能退回资料处理流水线。

## 与现行项目的关系

原生模型、文字圈选、普通联合训练及双向匹配原型已经存在；任务投影共用、移除真实区域几何统计的直接输入、多正确对应与不确定组合排除属于本目录的待实施完善。空间关系已经能够从标签提取，但尚未完整进入当前匹配描述。

本目录不改模型、实验门槛、历史结果或训练预算，也不恢复旧版多表现与空间结构两项机制。后续制图完成后仍需人工核对箭头和说明，不能把画得完整视为研究已经完成。
