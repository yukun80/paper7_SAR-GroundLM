# 完整目标架构设计

本页是**待实施的论文目标设计**，不是新实验结果。只检验一个问题：相比普通联合训练，区域—描述约束能否同时减少 SAR 地物误检、漏检并改善独立区域理解？第一阶段为 Qwen3.5-0.8B、全部11类、文字指定区域；依据[研究提示词](../../doc/research_idea.md)，沿用[原评价门槛](../evaluation.md)。

## 1. 主流程与模块接口

设图像为 $I$、目标文字为 $t$、问题为 $q$、预测区域为 $\hat M$、回答为 $\hat a$。真实训练区域 $Y_k$ 与有效标注范围 $V$ 只进入监督；255不当作背景。固定11类只是本轮训练评价范围，不是输出层的类别表。

| 部分 | 输入 → 输出 | 明确连接 |
|---|---|---|
| SAR Input Adapter | 单/双通道SAR → 三通道浮点图 | 沿用当前数值处理，不补造极化或物理单位 |
| Qwen Native Vision Encoder | 图像 → 原生视觉信息 $F$ | 同时送视觉合并与区域输出 |
| Native Visual Merger | $F$ → 语言可读取的视觉信息 | 保留Qwen原生连接，不增加独立视觉编码器 |
| Qwen Language Model | 视觉信息、$q,t$ → 回答前状态 $h_q$ 和回答 $\hat a$ | 目标/描述的纯文字编码复用同一语言模型参数 |
| Shared Visual Projection | $F$及固定网格坐标 → $X\in\mathbb R^{H_d\times W_d\times128}$ | 复用轻量解码器中像素打分之前的图像路径，不读目标文字或真实区域统计 |
| Shared Text Projection | 目标文字状态 $h_t$ → $u_t\in\mathbb R^{128}$ | 描述状态也经过同一投影；对应现有目标投影与原型映射的组合 |
| Lightweight Mask Decoder | $X,h_q,u_t$ → $\hat M\in[0,1]^{H\times W}$ | 回答前状态另经查询投影，与 $u_t$ 相加后匹配像素，恢复原图大小 |
| Language Answer | 原生语言输出 → $\hat a$ | 标准答案不进入圈选查询；生成的回答也不回送圈选部分 |

圈选的简化写法为 $z_i=s\,\cos(X_i,P_q(h_q)+u_t)+b$，随后恢复原图大小并取概率。这里 $P_q$ 是查询投影，$s,b$ 是可学习量。目标文字编码、标准圈选指令与用户问答可分次调用同一语言模型；参数共用不意味着所有输出只计算一次。

主路径始终是“图像与用户要求 → 区域和回答”。目标文字产生统一圈选指令，区域问答另行调用；预测时不需要训练标签、描述标准答案、匹配矩阵或困难类别表，也不循环修改区域。给定真实/错误区域回答属于单独的评价条件，不是主预测的必需输入。

## 2. 支撑步骤：Verified Region Facts

每条训练资料绑定原图身份、所属划分、区域范围、有效范围及事实。主要区域是某类全部有效像素；同类语义连通块仅用于局部错配训练，文字须注明 `selected semantic component`，不能声称为真实实例。

类别来自标签；位置沿用九宫格中心；面积为 $|Y_k\cap V|/|V|$；形态沿用可复算的标签几何描述；空间关系使用两个明确参照区域的中心差，沿用图像宽高5%的对齐容差。面积文字沿用整数百分比，保留精确值供核对。关系必须同时记录参照类别和范围。

事实只在有效标注范围内成立；“未标到”不能扩大为整张图一定不存在。无有效像素、参照不明、标签不支持的关系不生成确定描述。未标注区域截断的形态只描述已标注几何，不猜完整物体。用途、材质、散射原因不由标签推出。

空目标继续进入分割及存在性语言监督，但不构造空区域的正匹配向量。同一图片及全部文字留在同一划分。SARLANG仅提供已有语言问答，不为它虚构像素监督；TerraCoT不进入本轮。

## 3. 核心组成一：Confusion-Aware Pair Construction

基线开发结果按[现行规则](../evaluation.md)选定并冻结2—3组困难类别。开发数据只决定类别清单，区域、描述和错误组合全部取自训练数据；支持不足则不启动正式困难比较，不画出虚构的“已确定困难类”。

候选优先级：①困难类别间的类别错配；②同类但位置/范围不同的错配；③其他有明确事实矛盾的区域—描述错配。每张训练图最多取两个非空候选区域，先满足类别困难对，再补同类不同位置；跨图候选仅限同一训练更新内的两张图，最多四个区域，不新增外部数据或历史特征队列。

对候选区域 $r_i$ 与描述 $d_j$，构建 $C_{ij}\in\{+,-,?\}$。只判定描述明确表达的事实：全部受到接收区域及其原图支持则为 $+$；存在明确矛盾为 $-$；信息不全、范围不一致且无法核验或关系参照不明则为 $?$。描述对应的类别全区域与选定连通块不可静默混用。

描述文字相同或来自另一图片，不足以判错；只要所述事实同样成立，就保留多个正确对应。近似/取整后的面积描述按实际表达核验，不因底层数值微小差别制造假负例。位置错配需类别相同且位置事实明确冲突；关系错配需原图提供明确参照。

无可信错误候选时跳过该锚点的匹配项；一个图没有足够区域仍正常学习原分割和语言任务。不通过把 $?$ 改为 $-$ 来凑数量。输出区域索引、描述、三态对应表和错配理由，供两个训练方向共同使用。

## 4. 核心组成二：Bidirectional Region-Text Alignment

训练真实区域只作为 $X$ 的汇聚权重。$w_{ki}=\operatorname{AreaPool}(Y_k\cap V)_i$，$r_k=\operatorname{norm}(\sum_iw_{ki}X_i/\sum_iw_{ki})$；面积平均保留小区域的分数权重，不用最近邻把它抹去。分母为0时跳过。

描述经共用语言模型得到 $h_{d_j}$，再经主任务同一个 Shared Text Projection 得到 $d_j=\operatorname{norm}(P_t(h_{d_j}))$。区域与描述均为128维。**不再用独立的区域/描述匹配投影，也不把标签算出的中心、面积、长宽比直接拼入匹配输入。** 固定网格坐标可以保留，它们不依赖真实标签；这减少几何捷径，并不证明捷径已完全消除。

描述编码是训练专用调用，不把其状态或标准答案送入主预测调用。图中重复显示语言模型/文字投影时，以相同参数符号或无箭头局部细线标共用，训练支路的实线不能合入主预测实线；只有训练产生的参数更新影响后续预测。

令 $S_{ij}=r_i^\top d_j/\tau$，$P_i=\{j:C_{ij}=+\}$，$N_i=\{j:C_{ij}=-\}$。区域找描述的目标为：

$$L_{R\to T}=-\frac1{|\mathcal I|}\sum_{i\in\mathcal I}\log\frac{\sum_{j\in P_i}\exp S_{ij}}{\sum_{j\in P_i\cup N_i}\exp S_{ij}},\qquad\mathcal I=\{i:|P_i|>0,|N_i|>0\}.$$

描述找区域按对应表的列计算同式，$L_{align}=(L_{R\to T}+L_{T\to R})/2$。不确定项不进分子或分母。某方向无有效锚点时仅平均有效方向；两边都无有效锚点则该项为0。多个正确对应不会被互相推开。

学习影响必须同时到达 Shared Visual Projection、原生视觉可训练部分、Shared Text Projection 和共用语言可训练部分。区域选择与文字事实本身不求导；不要画成一个独立匹配分类器，也不要把反向学习箭头画成预测反馈。

总目标为 $L=L_{seg}+L_{lang}+\lambda L_{align}$；$L_{lang}$ 汇总相同的图像/区域语言监督及已有SARLANG问答。正目标沿用平衡二值误差与Dice，无目标仅用有效负像素误差。A取 $\lambda=0$，B取 $\lambda=0.1$，初始 $\tau=0.07$；后两值沿用当前设置作设计起点，不代表最优值。

A、B使用相同候选、正确描述、样本顺序、结构、初始权重与更新次数，B只增加匹配目标。错误描述不作为正确语言答案。A关闭的是附加目标，不是移除主任务共用投影；新增计算单独记账。

## 5. 当前实现与目标设计的差别

| 内容 | 当前实际状态 | 本目录的待实施完善 |
|---|---|---|
| 原生视觉、语言与文字圈选 | 已实现并运行基础检查 | 保留主路径，不扩大模型 |
| 匹配表示 | 独立区域/描述投影，区域端拼接4项真实几何量 | 改为任务投影共用，取消真实几何统计直接输入 |
| 正负组合 | 每图最多两个，交叉组合按错误处理 | 训练更新内候选、多个正确对应、明确排除不确定项 |
| 区域事实 | 类别、位置、面积、形态用于描述；关系另行提取 | 补齐关系参照、表达范围和对应判定后再用于匹配 |
| 作用证据 | 原型已检查视觉/语言两侧的学习影响，未完成有效A/B比较 | 新连接仍需实际验证，不能继承原型的通过记录 |

当前程序见[模型说明](../model.md)及[实现](../../sar_groundlm/core/model.py)。本目录仅提供设计和制图文本，不实施以上变更；图外图注必须保留 `Proposed architecture; effectiveness unverified.`，不排成模型内部说明框。制图画法见[目录约定](README.md)。

## 6. 需要的验证与图件边界

- 对相同事实的不同文字/不同区域、不确定对应、单区域、空目标和标签255做对应核验；确认没有人为制造错误标签。
- 单独检查匹配目标是否影响两个主任务实际共用的部分；答案替换不得改变提前圈选，真实几何统计不得绕入匹配输入。
- 保留原16图门槛，基础学习通过后再做公平A/B；所有类别成绩、困难类别误检漏检与无目标误圈均报告。
- 独立人工审核问答按自主、预测区域、真实区域、错误区域分别评价；共同改善、重复稳定及整体成绩代价按既定规则判断。
- 随机错误对照默认关闭，仅在核心比较值得继续且原预算允许时补做；必要的几何捷径诊断不扩展为新研究任务。梯度存在不等于学会、匹配变好不等于H成立。
- 图中不加入未见类别、光学分支、尺度学习、独立大分割器、多轮反思或旧版多表现/空间结构机制；不放虚构成绩。
