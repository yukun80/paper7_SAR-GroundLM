# 检查门槛与评价边界

先确认固定训练图能学会，再进行正式比较。当前未通过学习门槛；程序检查通过不能代替算法有效。[结果](results.md)

## 进入比较的要求

固定 16 张训练图，每张分别查询存在和不存在的目标。正目标每张重合比例至少 30%、平均至少 60%；不存在目标时误圈不超过有效面积 1%。给定正确区域的位置回答至少 12/16，并超过固定回答。

冻结阶段先通过，再共同学习；临时检查权重不进入六组正式比较。六组保持相同语言内容、顺序、数据和共同起点，只比较全部完成的 20、50、100 次更新阶段。第一轮和第二轮数据不同，不横跨两轮计算创新收益。

## 区域与结构

默认圈选阈值为 0.5，所有统计排除无效图像与未标注标签。逐文本目标报告二值 IoU，有正例类别才计入均值，无正例单列误圈；不冒充互斥 11 类预测成绩。

边界容差 2 像素，并排除未标注位置邻近边界；小语义区域至多 64 像素、覆盖至少 50% 为命中。水体细长部分采用局部半宽不超过 3 像素的骨架覆盖，内部误圈只在真实标注的内部非水区域统计。小连通块命中不是实例检测。

附加地面规则为 6,400 平方米、20 米边界距离、30 米水体半宽，仅适用已知尺度，不替换原成绩或门槛，也不是最佳参数。未知尺度单列；斜切网格面积可计算，距离不作不准确近似。[诊断](diagnosis.md)

## 语言与联合判断

分别报告不提供区域、提供预测区域、真实区域、错误区域四种条件。区域内保留原图，区域外采用中性灰色，不给出文字答案。错误区域按实际所给区域的位置评分，不能沿用原目标答案。

位置按固定解析、原生问答按严格文本匹配；分割和位置联合正确要求 IoU 至少 0.5 且位置答对。问题中已经给出的类别名称不计为模型自行识别。

标签衍生位置和面积不代替专家语义审核；原生问答也未全部经过本项目专家核验。自由描述保留原文、待人工审核，无依据描述比例没有审核就留空。正确区域条件成绩不能代表自由预测能力。

## 研究结论边界

最终留出只在设置确定后打开；本次尺度诊断仅用训练资料。第一轮留出已用于历史失败分析，不再用于选择新设置。

B3 − B1 − B2 + B0 仅是描述性交互量，正值不证明协同。单随机种子、短训练和参数容量差异需要后续独立检查；未完成专门类别隔离、跨卫星测试和人工区域评价，不宣称这些能力。
