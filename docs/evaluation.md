# 检查门槛与评价边界

先确认固定训练图能学会，再开放正式比较。程序检查通过不能代替模型有效；当前状态见[实际结果](results.md)。

## 基础学习

原16张训练图及其正目标不换；每张再查询一个不存在的目标。正目标每张重合至少30%、平均至少60%，无目标误圈不超过有效标注面积1%。给定正确区域的位置回答至少12/16并超过固定回答。

允许普通联合训练后检查这些要求，取消旧流程额外的冻结阶段前置门槛。检查权重只供诊断，不作为正式起点。缺少任何图、语言检查或对应权重，均不放行正式比较。

## 分割、混淆与困难类别

圈选阈值固定0.5。11个文字类别分别报告二值重合、精确率、召回率、误检率和漏检率；统计排除图像无效位置和标签255。误检率分母为真实非目标有效像素，漏检率分母为真实目标像素。不存在分母时记为缺失，不假装为0。

每类先汇总像素计数再计算成绩；整体为有正目标支持的类别平均。无目标查询另报平均和最大误圈比例，不混入正例重合。

互斥混淆表要求同图全部11次查询：每像素取最高分，全部低于0.5记为未检出，同分按类别编号顺序。未检出不是背景类，表为11行、12列；独立二值成绩仍保留。

困难类别只来自开发集，每类至少三张正例图、256个有效目标像素。按两个方向的类别归一化混淆率平均排序，最多固定三组；不足两组则停止困难比较，不用最终测试补选。排序支持量与不确定性一同保存。

## 语言与共同正确

分别保留不提供区域、提供预测区域、真实区域、错误区域四种条件。所给区域以外置为中性灰；预测区域只使用模型输出和图像自身有效范围，不使用标签有效范围裁切。错误区域按实际所给区域的事实评分，同时保留其相对真实目标是否正确。

位置、存在和面积用明确答案评分；圈选与回答共同正确要求重合至少0.5且目标问题答对。问题中已经给出的类别名称不算自行识别。

独立人工审核采用批准或拒绝候选问题，需记录审核者和时间。审核可删除不可靠问题，不能静默改动已封存图像和标签。空间关系题只在完整图像条件下评价，因为遮去其他区域后无法公平判断类间关系。

自由描述保存原文，最多生成64个词元，不补写截断内容；未单独人工裁决时事实正确率留空。自动标签衍生问答与历史给定真实区域的高分都不能代替独立语言证据。

## 最终测试与结论

训练和开发图片、近似重复及衍生文字不能进入新的约100张独立问答集。现有64张留出保持原样；新候选单独生成，不改原清单。完成共同阶段并封存模型、困难类别、阈值和评价规则后才能建立候选，人工审核后才能最终评价。

A、B只比较相同更新阶段。三次重复、误检漏检及自主问答共同改善、整体下降不超过1个百分点，才满足完整支持的基本条件。仍须审查不确定性、最差案例和其他解释。

历史水体边界、细线及地面尺度统计只作为已有诊断，不是当前主实验新增目标。其原始定义与结果保留在[诊断](diagnosis.md)及旧程序中。
