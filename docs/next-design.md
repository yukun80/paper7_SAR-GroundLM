# 下一步设计与尺度接口

## 本轮交付状态

已实现独立尺度读取、缩放后的几何换算、附加地面指标和一次预测诊断。没有修改 Qwen、区域输出、区域语义或空间结构的学习代码，没有训练新的分支。当前模型仍按第二轮原设置工作。

下文的模型连接方式是待验证设计，不是已经获得收益的实现。基础学习和公平比较的门槛保持不变。原核心假设仍是：共享的区域监督能否同时改善 SAR 区域识别与语言理解。

## 真实数据与信息边界

训练分割资料为 64 张地面尺度未知的灰度图、32 张像素间距 4.6875 米及32张像素间距10米的双通道图。三组都保留。不得根据类别、图片尺寸或默认单位矩阵猜测地面尺度。

文件的像素间距只描述采样网格，不是传感器实际空间分辨能力；它也不能证明两张图来自相同成像模式。[官方产品说明](https://sentiwiki.copernicus.eu/web/s1-products)分别列出空间分辨能力与像素间距。

既不统一把所有图片重采样为某个地面间距，也不通过放大图片宣称获得更多细节。当前只按原输入补算；实际分辨能力、成像模式和强度物理单位尚不明确时，不进行伪装成真实雷达退化的模糊或缩放实验。

## 已实现的数据接口

`data.scale.read_scale(image_path, label_path)` 返回独立记录，不改原清单和原图：

| 字段 | 含义与约束 |
|---|---|
| `status` | `known_pixel_spacing` 或 `unknown`；未知不替换成数值1 |
| `shape_hw`、`transform`、`crs` | 原图大小、仿射位置关系、文件声明的坐标系统 |
| `source_unit`、`metres_per_unit` | 原单位及经过确认的米制换算；角度单位不直接换算为米 |
| `pixel_basis_m`、`spacing_xy_m` | 两个像素方向的米制向量及长度，保留旋转和非方形像元 |
| `pixel_area_m2` | 用两个方向构成的面积计算；斜切网格不能简单相乘两个边长 |
| `footprint_corners_m`、`footprint_area_m2` | 整张图的地面范围；只用于来源核对和几何对应 |
| `orthogonal`、`alignment` | 能否直接用横纵米制距离；图像与标签对应的依据 |
| `sensor_resolution_m` | 当前全部为未知，不根据像素间距填入 |

`processed_geometry(source, input_hw, grid_hw, merge)` 按实际进入模型的网格计算新的像素间距、视觉网格单元和合并单元对应的地面跨度。只在同一图像范围内缩放；裁剪或补边不能冒充此接口支持的纯缩放，未来必须另外传入窗口位置和有效范围。

Qwen 的早、中、晚阶段在现有设计中使用同一尺寸的空间网格。逐级放大特征只是预测恢复，不能改写原始地面尺度或传感器分辨能力。网格单元的地面跨度也不等于模型的实际感受范围。

## 两项改进的下一版连接约定

### 区域语义

下一版拟在原文字目标、当前图像信息之外，允许读取像素间距、有效覆盖范围大小和“已知/未知”状态。目标仍由用户文字指定，不根据标准答案、真实区域大小或标签构造目标表示。

间距信息在形成目标外观表现时使用，帮助区分相同像素大小对应的不同地面范围。未知尺度不参与数值换算，原图文路径保持可用；已知尺度信息缺失时也必须能够运行。

模型不需要读入来源文件名、绝对地理坐标或根据来源猜测的类别。所有正式组接收同样的尺度信息及未知状态；不得把额外信息带来的改善直接归为四种外观表现的作用。数据中某些类别与尺度分组相关，还必须检查模型是否只利用了这种来源关联。

### 空间结构

保持 Qwen 原生早、中、晚阶段及共享写回路径。已知尺度时，区域面积和距离约束使用原图上的米制对应关系；未知尺度时保留原像素规则，损失和评价均单独记录分母和样本数。

恢复后的输出继续与原图标签逐像素对应。小区域不在低分辨率标签上被抹去；未知标注不作背景，不用于推断孔洞。非正交网格的米制面积可以计算；本轮距离项不作不准确近似。未来若支持此类距离，须单独验证计算方式。

所有共享影响仍须可以切断，包括文字目标、图像、区域表现、空间细节，以及未来尺度信息的学习路径。只给数据添加尺度字段并不能算这些新路径已经实现或通过检查。

## 附加评价与公平边界

原验收仍为：平均重合至少60%、每张至少30%、无目标误圈不超过1%。本轮以10米组为参照，附加查看6,400平方米小连通块、20米边界容差和30米水体近似半宽；不把这些数值认定为最佳设置。

B0 当前没有启用空间附加损失。因此米制指标与旧像素指标的差别，仅能表明比较规则的地面含义变化，不能证明它导致 B0 训练失败。

16张固定练习图的两个已知尺度组没有共同受检正目标类别，不能形成有效的尺度效果比较。后续若获准研究，只检查相同类别、相近目标大小及其他可比条件；跨来源比较仍不能单独证明尺度因果关系。

## 本轮运行与接续

```bash
./run.sh --config configs/pilot_v2.json diagnose
```

该入口只读原训练资料及冻结阶段640次更新的原模型。首次尝试限时45秒，计入原20分钟准备上限；重复运行复用预测文件，不再加载模型。异常中断也保留尝试标记，不自动删除标记重跑。

结果保存在 `artifacts/diagnosis_v1/`，报告见 [地面尺度诊断](diagnosis.md)。实现错误先处理；数据不足则明确停在证据不足，不启动正式六组、开发或最终留出评价，不自动实施上面的学习分支。
