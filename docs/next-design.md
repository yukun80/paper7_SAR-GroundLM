# 下一步条件与待实施设计

本页只记录尚未完成的研究，不把程序具备入口写成实验已经完成。当前事实见[实际结果](results.md)。

## 先解决基础学习

固定16图的原门槛必须全部通过。现行检查允许普通联合学习，并修正目标提问和无目标轮换；是否有效由真实结果决定。仍失败时优先分析已保存的逐图预测、目标响应和训练记录，不自动扩模型或搜索大量设置。

## 基础学习通过以后

先用开发预测固定困难类别，再运行相同起点和条件的A/B比较。双方没有共同完成的阶段不得报告收益。随机错误匹配对照只在核心比较有效、仍有预算时讨论，不默认占用资源。

独立约100张问答候选需要人工审核。完成审核前只保留候选和自动检查，不宣布独立语言理解改善。三次重复和代表性失败分析尚需按实际完成情况补齐。

## 暂不实施

2B、4B、未见类别、国产卫星跨域、洪水与阴影专项、光学融合和部署优化均不在本轮。是否扩展取决于0.8B对H的证据与另行明确的资源。

旧的尺度读取得到保留，但尺度接入学习、多表现增强及空间结构机制不进入当前A/B主线。已有尺度诊断不能证明失败由地面尺度造成。

## 人工负责的环节

人工审核独立问答语义、无法由标签推出的SAR事实、特殊数据权限、新增大规模预算及最终科研结论。日常报告刷新不重新加载模型或启动训练。
