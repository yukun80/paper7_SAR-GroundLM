# 当前模型与公平比较

现行框架只围绕[核心假设](paper-design.md)。实现了比较所需能力，不表示已经取得方法收益；是否完成实验以[实际结果](results.md)为准。

## 同一套模型，两种训练方式

使用 Qwen3.5-0.8B 原生视觉和语言部分，复用 SAR 浮点输入处理及轻量区域输出。目标由用户文字给出，没有固定11类分类输出替代主任务。

A：普通语言与分割联合训练。B：在相同结构、训练图片和语言内容上增加区域—描述匹配约束。原多表现写回、空间结构增强和尺度学习不参与这次比较；旧实现保留，历史权重仍按历史入口读取。

区域预测统一使用同一个目标指令，训练答案位于查询之后；训练、检查和公开预测一致。用户的额外问题用于生成回答，不改变标准圈选要求。原生视觉最后四层、视觉合并和语言最后两层及末端标准化允许共同学习。

## 训练阶段的双向匹配

训练真实掩码在原生视觉信息上汇聚区域内容，并附带该训练区域的中心、面积与外接范围比例。描述由相同语言模型编码；两边各映射到128维，使用区域找描述和描述找区域两个等权目标。温度0.07，附加权重0.1，固定而非搜索所得。

每张图最多选两个可验证的正确区域—描述组合，交叉组合构成错误匹配。优先采用已冻结的混淆类别；同图不具备两类时，可用描述确实不同的同类语义连通块。空区域、重复描述不伪造匹配对；同图没有合适组合就跳过该附加项。连通块不宣称为实例。

A、B接收相同的正确区域语言内容。错误组合只进入匹配约束，不作为正确语言答案。匹配影响须进入原生视觉和语言部分，不能仅更新附加投影。

区域掩码和其几何信息只用于训练匹配。公开预测不读取真实标签、答案或标签统计，不执行反思、循环重定位或多轮分割。

## 学习与比较安排

原固定16图先进行256次轻量圈选练习，再允许最多384次普通联合更新；诊断总计最多30分钟，受原预算余额进一步限制。冻结阶段的成绩用于诊断，不再作为允许联合学习的额外前提。正目标与无目标分别轮换，每64次安排覆盖16个正目标各三次、16个无目标各一次。

通过全部原门槛后，困难类别先由单独的64次基线选择实验确定。该选择实验不作为正式A组；随后A、B从同一原始模型起点重新训练，使用同一困难类别表、图片顺序、语言内容和更新次数。正式阶段为64、128、256次，每次包含两张分割图；各轮先保留11类正例，再安排四分之一无目标要求。

先用种子42；只有完整成对阶段和预算允许时才考虑43、44。随机错误匹配对照默认关闭。新增约束计算时间和每次完整更新耗时分别保存。短程训练完成不等于充分收敛。

## 保存与隔离

新的模型、数据、设置和训练来源共同标识实验。新旧权重不混用；学习检查权重不得作为正式共同起点。保存包含允许学习的参数、优化器、随机状态和进度；中断只恢复已安全保存的更新，领先日志另存以便追溯。
