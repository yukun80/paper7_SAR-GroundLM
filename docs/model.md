# 当前模型与公平比较

本页说明已实现的设计，不代表已经验证有效。[实际结果](results.md)与[下一步设计](next-design.md)分别记录。

## 模型

Qwen3.5-0.8B 原生视觉部分提供图像信息。区域目标单独进入文字条件；训练答案在目标查询之后，不能提前参与区域预测。区域输出不使用固定 11 类分类表。

区域机制在基础组启用一种表现，增强组启用四种。各表现读取当前图像，再与文字共同形成匹配，并给非目标保留独立竞争位置。差异约束防止四种完全重复，不要求每张图平均使用四种。

空间机制取原生视觉早、中、晚信息，逐级放大、融合后提供细节；同时将恢复信息写回 Qwen 使用的图像部分。三个原生阶段本身的空间尺寸相同，不能把取多个阶段直接称为已经获得高分辨率。边界、小区域、细线和内部非水区域分别监督，未知标签不用于推断孔洞。

## 公平比较

临时检查结果不进入六组。通过门槛后，从原始 Qwen 重新准备共同起点，仅训练区域输出部分，共同视觉和语言保持冻结。随后六组使用相同共同起点、样本顺序、语言问题和回答。

冻结区域学习与最终检查必须分别通过。此次发现初版检查提前继续训练，已经修正；实际执行偏差和原代码快照记录于 [实际结果](results.md)，不能把设计要求写成已经严格执行的事实。

每次正式更新包含两张分割图片及两张原生问答图片，按完整轮次安排。每轮先为各可用类别保留正例，再分配四分之一无目标要求；稀有类不会全部被安排为负例。仅语言组没有像素误差；独立分割组切断像素误差对图像、语言目标、多表现和空间细节的所有影响，同时保留正常语言学习。共同部分与分割输出分别限制更新幅度，防止间接影响。

六组只比较共同完成的阶段。原生问答、区域语言和分割分别统计；输入新增通道带来的变化不能归因为两个创新模块。仍需更充足训练、多个随机起点、等容量比较与独立人工区域语言评价才能研究核心假设。

## 文件组织

- `data/`：读取、固定样本、任务文字与真实标签事实。
- `modeling/`：原生模型连接、区域输出、两种共享机制。
- `engine/`：预算、训练、学习检查、保存恢复、入口。
- `evaluation_v2/`：固定规则评价、预测图片和实际报告。
- `legacy_v1/`：第一轮冻结实现；根目录同名文件只是兼容入口。
- `configs/`：统一实验设置；模型、数据、训练、评价共用。

旧权重的代码校验针对冻结目录中的原实现。第二轮权重单独记录模型来源、数据清单、实验设置与代码版本，不静默混用。


仅语言组也使用相同的标签衍生语言内容；它表示没有额外像素误差，不表示完全没有标签信息。分割影响切断时，共享部分与区域输出分别限制更新幅度，避免间接改变共同更新。

保存内容包括可训练参数、优化器、随机状态、基础模型和清单身份。加载一致与继续更新一致分别检查。旧版实现保留供历史权重使用。
